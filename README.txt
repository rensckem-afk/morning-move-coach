MORNING MOVE COACH — 10K FINAL PROTOTYPE

12-week gradual 10K program.
Weekly rhythm:
Monday: Run/Walk
Tuesday: Strength + mobility
Wednesday: Run/Walk
Thursday: Recovery walk
Friday: Run/Walk
Saturday: Long easy session
Sunday: Recovery walk

One herb is taught for two consecutive days:
Day 1 = identification/description.
Day 2 = actions/uses.
Starts with Chamomile.

Includes:
- Voice + beep interval cues
- 5-minute warm-ups on run days
- 10-minute warm-up/cool-down on long days
- 30-minute recovery walks
- Basic strength circuit
- Repeat-this-week option
- Week selector
- Day selector
- PWA manifest

This is a browser/PWA prototype. For true screen-off/background audio on Android,
it needs to be packaged as a native Android app or installed as a properly configured PWA.
